## Design Decisions

The portfolio uses a simple and clean color scheme with dark blue navigation and light-colored sections. Flexbox is used for navigation, while spacing, shadows, rounded images, and hover effects improve the overall appearance and user experience.

## Design Decisions

The portfolio uses a simple and clean color scheme with dark blue navigation and light-colored sections. Flexbox is used for navigation, while spacing, shadows, rounded images, and hover effects improve the overall appearance and user experience.

## Responsive Design

Media queries are used to make the portfolio responsive on smaller screens. The navigation links are arranged vertically on mobile devices, and spacing and font sizes are adjusted for better readability.

## Testing

The portfolio was tested in a web browser to check navigation links, hover effects, profile image styling, section layouts, and responsive CSS behavior.
